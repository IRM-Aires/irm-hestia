# Hestia — sitio web de IRM Aires

Páginas públicas de Hestia (la página de inicio de las herramientas de IRM Aires) y del
formulario «Reportar». Se generan automáticamente; no se editan a mano.

Las páginas no traen datos: solo la llave pública del servicio de datos. Todo lo demás lo
protegen el inicio de sesión y los permisos de la base.
